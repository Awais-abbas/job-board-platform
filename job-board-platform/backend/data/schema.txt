Job Board Platform - Dummy Data Schema
========================================

## USERS TABLE
{
    "id": int,

    "name": string,
    "role": "job_seeker" | "recruiter",
    "created_at": timestamp,
    "updated_at": timestamp
}

{
    "id": int,
    "user_id": int (foreign key to users),
    "role": "job_seeker" | "recruiter",
    "bio": string,
    "location": string,
    "website": string,
    "cv_path": string (path to uploaded CV file),
    "company": string (for recruiters),

    "skills": [string],

    "education": [{degree: string, field: string, school: string}],
    "created_at": timestamp,
    "updated_at": timestamp
}

## JOBS TABLE
{
    "id": int,
    "recruiter_id": int (foreign key to users),
    "title": string,
    "description": string,
    "required_skills": [string],
    "experience_level": "entry" | "junior" | "mid" | "senior" | "lead" | "principal",
    "salary_min": int,
    "salary_max": int,
    "status": "active" | "closed" | "archived",
    "applicants_count": int,
    "created_at": timestamp,
    "updated_at": timestamp
}

## APPLICATIONS TABLE
{
    "id": int,
    "user_id": int (foreign key to users),

    "status": "pending" | "accepted" | "rejected",
    "resume_used": string (path to specific resume version used),
    "applied_at": timestamp,
    "reviewed_at": timestamp
}

## API RATE LIMITING
- Not implemented yet (can be added for production)
